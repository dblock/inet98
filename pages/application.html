Software available on Public PCs and MACs
http://www.inet98.ch

Overview

This section describes the public PCs and MACs configurations available at INET '98. You can use the Internet Access Room (IAR, open from 7:30 AM to 10:00 PM, non-stop) to access the Internet or work with your documents. All configurations have printers connected.

For unanswered questions, please refer to the Q&A Forum at http://www.inet98.ch/forum.

Software available on public PCs:
PCs run under Windows 95. There are three distinct PCs configurations: Desktop Publishing, Internet Access and Speakers Desk. PC Software is distributed using a boot ROM system described at http://cuiwww.unige.ch/info/pc/remote-boot.

Software applications available on public PCs:
  • Microsoft Powerpoint 95 & 97 (Desktop Publishing)
  • Microsoft Word 95 & 97 (Desktop Publishing)
  • Microsoft Excel 95 & 97 (Desktop Publishing)
  • Microsoft Internet Explorer 4 (all cnfigurations)
  • Netscape Navigator 4.05 (all configurations)
  • Windows 95 Telnet (all configurations)
  • WS-Ftp 95 (all configurations)
  • PC Pine IMAP EMail Reader (all configurations)
  • Software Launcher replacing Explorer (all configurations)
Software available on public MACs:
  • Microsoft Word 98
  • Microsoft Excel 98
  • Microsoft Powerpoint 98
  • Microsoft Internet Explorer 4
  • Netscape Navigator 4.05
  • NCSA Telnet 2.7b
  • Adobe Acrobat Reader 3.01
